# Hide Users for Venus

Le patch 0.4.4 masque localement les membres bloqués ou ignorés, leurs indications de saisie et certaines entrées du détail des réactions. Il cible Discord Android **351.11 - Stable** (`com.discord`, code 351011).

Dans Morphe, charge [Venus Patches](https://github.com/VenusIsJaded/Venus-Patches) puis sélectionne **Venus settings** avec **! Hide blocked or ignored users**. L’application des deux patchs a été vérifiée avec Venus 1.21.1.

Le [MPP fourni](../releases/HideUsers_0.4.4.mpp) déclare la GPL-3.0.
