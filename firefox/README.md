# Firefox - Local Website Blocker

Le patch 0.1.2 applique des règles locales aux URL HTTP(S) dans Firefox Android 159.0 (`org.mozilla.firefox`). Configure les adresses et chemins dans les options du patch de Morphe avant de générer l’APK.

Le [MPP fourni](../releases/Firefox-Local-Website-Blocker-0.1.2-URL-Reddit.mpp) déclare la [MPL-2.0](https://www.mozilla.org/MPL/2.0/).
